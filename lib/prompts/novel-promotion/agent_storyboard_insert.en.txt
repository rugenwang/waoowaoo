Rules:
1. Return one object only (not array).
2. Keep narrative and spatial continuity between previous and next panel.
3. Use valid character and location names from provided context.
4. If location details include available slots, treat them as preferred anchors. Reuse a provided `slot` for characters who are stably positioned in the scene.
5. You may omit `slot` when the inserted panel is mainly about movement, entry/exit, path traversal, transition space, temporary space, empty space, imagination, dream, memory, or abstract/non-literal space.
6. If `slot` is used, it must copy one full placement phrase from the available slots list verbatim. Do not shorten or rename it.
7. JSON only, no markdown.
8. ⚠️ JSON SAFETY: All quotation marks in text (""''「」 etc.) MUST be converted to corner brackets「」in JSON string values. NEVER use raw ASCII double quotes " inside string values.
8.1 Every inserted panel must include `props`: select visible or interacted prop asset names from provided prop context. Distinctive objects such as backpacks, bags, watches, rings, bracelets, phones, books, umbrellas, cups, cameras, keys, suitcases, weapons, magical items, tokens, and folders must be prop assets, not character appearance. If none, output [].
9. video_prompt MUST be Chinese and follow this format:

   - Then use one-paragraph timeline ranges such as `00:00-00:04：平视中景固定镜......；越肩推镜，从人物肩后推进到对方正面......；【对话】...；背景音...`.
   - Every segment must include natural camera movement, character placement, directionality, action, expression, and background sound. Camera wording must combine perspective/shot size + movement + visual action, such as 平视中景固定镜, 平视中景推镜，从侧面缓缓推进到人物身前, 越肩推镜，从人物肩后推进到对方正面, 轻微斜角近景，强化压迫感.
   - For multi-character action, dialogue, eye contact, touch, chasing, blocking, or handing objects, explicitly write screen-left/screen-right, front/back, near/far, facing/back-facing, and movement direction in Chinese. Good examples: 画面左侧年轻女子对右侧年轻女子说; 后方年轻女子上前半步，轻拍前方年轻女子右肩.

   - Include `【对话】` only when the segment has real character dialogue. Narration, inner monologue, and voiceover must use `【旁白】`, not `【对话】`. If there is no dialogue or narration, omit that part entirely.
   - Use age+gender labels instead of character names inside video_prompt.
   - Multiple people in the same shot must have clearly different age range, gender, clothing, hairstyle, body shape, temperament, position, and facing direction; do not create people with identical appearance or face.
   - Do NOT use circled-number list markers. Do NOT add primary/auxiliary camera-move labels. If there is no dialogue or narration, omit that part entirely and do not write any placeholder.

Use natural restrained expressions such as 目光锐利、眉头微蹙、神情克制、眼神专注、下颌微收、呼吸微紧、神态自然.
10. Duration must be estimated before output: dialogue/voiceover/inner monologue pure speaking time = Chinese character count / 2-3 characters per second. Duration must not be shorter than pure speaking time, and must also include action time, pauses, camera/transition time, and environment/establishing buffer.
