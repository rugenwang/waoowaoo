Module 2 — 【时间轴提示词】(Timeline Prompt, REQUIRED):
Precisely describes actions, dialogue, camera changes at each time point using format: AtXs: description.
- Time starts from At0s, increments through the panel duration
- Interval: simple actions 0.5-1s, complex actions 1-2s
- Minimum 3 time points covering the full duration
- Dialogue format: 说话人："内容" (use age+gender for speaker labels, e.g. 年轻女子, 中年男子)
- Use "+" for simultaneous actions
- Must include movement/dynamic elements, no purely static descriptions

Example:【时间轴提示词】

At4.5s：年轻女子抬手揉了揉眼睛，身体微微后仰，对着镜头笑："写了这么久，休息一下吧。"

Module 3 — 【辅助提示词】(Auxiliary Prompt, OPTIONAL):
Supplementary sound effects, prop details, etc. Omit if not needed.

Rules:

2. Keep source_text semantically aligned with input; do not rewrite story meaning.
