Key-frame group rules:

- Use panel_mode="group" for visible action change, scene transition, spatial movement, or multi-stage emotion/action. Output 2-20 frames based on duration + action density + transition/camera-movement density.
- Frame count guidance: 6-8s low density = 2 frames; 9-12s low/medium density = 3-4 frames; 13-16s medium/high density = 4-6 frames; 17-20s medium/high density = 5-8 frames.
- Increase frame count when there are many actions, position changes, prop interactions, multi-person interactions, scene transitions, flashbacks/dreams, or dense camera moves such as orbit, dive, tracking, whip pan, dolly, push, pull, or pass-through shots.
- Ultra-high density action/camera movement should approach 1 frame per second, capped by duration_sec, so a 20s group may use up to 20 frames. Use this for continuous fighting, melee, high-speed chase, repeated dodge/block/combo actions, explosion/falling, rapid cutting, continuous transitions, or dense whip-pan/pass-through/tracking camera combinations.
- If a non-ultra-high-density 20s beat needs more than 8 key states, split it into two top-level group panels. If it is clearly ultra-high-density action/camera movement, keep one group and output up to 20 frames.
- group duration_sec must be <= 20 seconds. single duration_sec should usually be 2-8 seconds; group duration_sec should usually be 6-20 seconds.
- Each frame must include frame_index, frame_time_sec, frame_role, dependency_frame_ids, image_prompt, video_prompt, reference_policy.
- frame_time_sec starts at 0, increases in playback order, and never exceeds duration_sec.
- dependency_frame_ids may only reference earlier frame_index values. Use it to keep the next generated image consistent with the prior frame or base reference.
- image_prompt must be a direct positive image-generation prompt and preserve character identity, clothing, scene, light, aspect, and visual style across the group.
- The first group frame (frame_index=0, frame_time_sec=0, frame_role="hero") MUST be the original state before the video action starts: the character has not completed later actions, emotional changes, movement, fight results, or transition results.
- The first frame image_prompt must explicitly describe before-action/original position/initial pose/initial expression and must naturally lead into later frames.
- Every frame image_prompt must state that characters are fully and properly clothed, with clothing consistent with character settings/reference images. Do not create shirtless, semi-nude, exposed torso, missing clothing, revealing outfit, or torn-clothing exposure unless explicitly required by the source text; even then keep clothing decent.
- When panel_mode="group", group_video_prompt must describe positive visual quality, background music style, segmented timeline, camera movement, characters, actions, expressions, dialogue, and transitions. Avoid exaggerated action.
- When panel_mode="single", do not output group_video_prompt.
