本检查规则只验证 WAOO 规则的执行结果，不替代或扩展 WAOO 的创作 Prompt。

结构化数据提交前必须检查：符合当前 JSON Schema；ruleSetVersion 与 ruleSetHash 未变化；artifactHash 与规范化数据一致；external key 唯一；所有引用已存在且类型正确；分镜组与分镜顺序稳定；分镜框架完整且先于图片；不包含模型、供应商、密钥或令牌配置。

资产或分镜图片上传前必须检查：文件可读取且格式受支持；画幅和分辨率符合项目设置；主体、身份、外观阶段、场景、时代、服装、道具和相邻镜头连续性符合对应 WAOO Prompt 与关联数据；无多余角色、错位文字、水印、明显肢体错误或关键主体裁切。

不合格结果不得上传或标记完成。可以在不改变 WAOO Prompt 和事实的前提下由 Codex 重新生成；仍失败时停止对应目标并报告可定位的原因。
